# Tona - Tu Nagual Digital

## Descripción
Tona es un agente académico personal impulsado por IA que organiza tus tareas, horario, documentos y correo — y te escucha cuando le hablas.

## Tecnologías
- React + Vite (Frontend)
- FastAPI (Backend)
- Supabase (Base de datos)
- Stripe (Pagos)
- Google Cloud (Gemini, TTS, OAuth)
- Railway + Netlify (Deploy)
